# SuperLorenz
Proyecto de Bases de Datos I e Interfaces de Usuario, hecho completamente a mano sin frameworks 💀

## Estructura del Repositorio

Este repositorio contiene dos proyectos principales:

### 📁 SuperLorenz-Web
Aplicación web del sistema SuperLorenz desarrollada con Java Servlets y JSP.
- **SuperLorenzWeb/**: Proyecto principal de NetBeans
  - `src/`: Código fuente Java (Servlets y clases)
  - `web/`: Páginas JSP, imágenes y recursos web
  - `nbproject/`: Configuración de NetBeans
- **Tomcat 10.1.33/**: Servidor de aplicaciones para Windows y macOS/Linux

### 📁 SuperLorenz-SQL
Scripts SQL para la base de datos del sistema SuperLorenz.
- **SuperLorenz V1/**: Primera versión del esquema de base de datos
  - `Dumps/`: Respaldos de la base de datos
  - `Scripts/`: Scripts SQL organizados por tipo (CREATE, INSERT, ALTER, UPDATE)
- **SuperLorenz V2/**: Segunda versión del esquema de base de datos (actual)
  - `Dumps/`: Respaldos de la base de datos
  - `Scripts/`: Scripts SQL para crear tablas e insertar datos
